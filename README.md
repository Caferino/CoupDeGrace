# Coup de Grâce

Minecraft 1.20.1 Forge mod that adds a GTA-style adrenaline rush visual effect after killing any living entity.

## Features
* **Adrenaline Rush:** Trigger a gameplay shift upon securing a kill.
* **Lightweight & Compatible:** It uses an overlay PNG to achieve its effect, allowing full compatibility with shaders and most mods.

Found a bug or a suggestion? Let me know under Issues!
